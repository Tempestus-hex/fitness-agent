# fitness-agent
**Назначение агента:** Помощник в отслеживании прогресса тренировок, роста или стагнации силовых показателей, а также частоты тренировок.

**Язык программирования:** `Python`

## Технологический стек
* Python 
* `rich` (цветной вывод в консоль)
* `black` (форматтер кода)
* `flake8` (линтер для проверки кода)

## Подготовка окружения и запуск
1. Клонируйте репозиторий и перейдите в папку проекта:
   `cd fitness-agent`
2. Создайте виртуальное окружение:
   `python -m venv .venv`
3. Активируйте его (в Git Bash):
   `source .venv/bin/activate`
4. Установите зависимости:
   `pip install -r requirements.txt`
5. Запустите приложение (находясь в корневой папке проекта):
   `python -m src.fitness_agent.main`

## Команды приложения
* `add` — добавить новую тренировку (запрашивает название, длительность и сожженные калории).
* `list` — вывести список всех тренировок с их статусом и показателями.
* `done` — отметить тренировку как выполненную по её номеру.
* `help` — показать справку.
* `exit` — выйти из программы.
Способ хранения данных: Данные хранятся в оперативной памяти и сбрасываются при перезапуске программы
## Сценарии

**Добавление тренировки и просмотр списка:**
> `> add`
> `Название тренировки: Становая тяга`
> `Длительность (мин): 22`
> `Сожжено калорий: 150`
> `Тренировка добавлена!`
> `> list`
> `0. ( ) Становая тяга (22 мин, 150 ккал)`

**Отметка о выполнении:**
> `> done`
> `Введите номер выполненной тренировки: 0`
> `Статус обновлен!`
> `> list`
> `0. (x) Становая тяга (22 мин, 150 ккал)`

## Проверка качества кода
* Форматирование: `black .`
* Линтинг: `flake8 . --max-line-length=88`
