# fitness-agent
**Назначение агента:** Помощник в отслеживании прогресса тренировок, роста или стагнации силовых показателей, а также частоты тренировок.

**Язык программирования:** `Python`

## Планируемые возможности
*   **Добавление тренировок:** запись типа тренировки, её длительности, счетчик сожженных калорий.
*   **Получение плана:** генерация плана тренировок на день в зависимости от цели (похудение, набор массы) и параметров пользователя.
*   **Напоминания:** уведомление о запланированной тренировке.
*   **Статистика:** вывод списка тренировок за последнюю неделю, общий показатель прогресса в тренировочном прогрессе.
